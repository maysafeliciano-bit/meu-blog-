# Meu Blog

Projeto desenvolvido durante as aulas de desenvolvimento web.

## Sobre o projeto

Este projeto consiste em um blog com várias publicações organizadas utilizando Flexbox.

O objetivo foi melhorar a aparência, a organização e a experiência de navegação do blog.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox

## Funcionalidades

- Organização dos posts com Flexbox.
- Layout responsivo.
- Tema claro.
- Tema escuro.
- Botão para trocar entre os temas.
- Transição suave entre as cores.
- Sombra nos cards dos artigos.

## Melhorias finais

Nesta etapa do projeto foram adicionadas:

- Correção da visibilidade do botão no tema escuro.
- Transição suave entre os temas.
- Efeito de sombra nos artigos utilizando `box-shadow`.
- Melhor organização visual dos posts.
- Responsividade para telas menores.

## Estrutura

- `index.html` - Estrutura da página.
- `style.css` - Estilos e aparência do blog.
- `posts.js` - Conteúdo dos posts e funcionamento do botão de tema.
- `README.md` - Documentação do projeto.
